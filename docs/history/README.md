## Policy / Regel

The repository editions are the maintained Markdown baseline. The consolidated specification is normative. Earlier Word/PDF/chat-export artifacts remain historical source material but are intentionally not treated as competing normative specifications.

Die Repository-Fassungen sind die gepflegte Markdown-Baseline. Das konsolidierte Pflichtenheft ist normativ. Frühere Word-/PDF-/Chat-Export-Artefakte bleiben historische Quellen, sollen aber nicht als konkurrierende Spezifikationen gepflegt werden.

When an earlier source contains detail that is not represented in the maintained repository edition, it should be restored deliberately through a documentation change rather than silently inferred.
