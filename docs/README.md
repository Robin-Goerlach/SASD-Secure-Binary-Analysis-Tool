# SASD Secure Binary Analysis Tool – Documentation

This directory is the documentation entry point for **SASD Secure Binary Analysis Tool / SASD Binary Insight**.

The structure follows established SASD repository conventions: language-specific product documentation is separated from architecture decision records, while requirements, research and strategy remain clearly distinguishable.

## Current normative baseline

The consolidated specification dated **2026-10-08** is the current product baseline. Earlier specifications and research remain useful as decision history but do not override it.

## Documentation policy

German and English documents describe the same technical intent. They do not have to be literal sentence-by-sentence translations, but normative requirements, release assignments, security boundaries and architectural decisions must remain equivalent.

Research documents are evidence and decision support. The consolidated specification is normative for implementation unless superseded by a later approved baseline or ADR.
